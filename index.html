Лот

Откроется окно Chromium на несколько секунд — Copart пускает только настоящий браузер. Фото скачаются в lots/<номер>/.

Заполнять автоматически ставить ничего не нужно
  1. Покажи панель закладок, если скрыта — Ctrl+Shift+B на Mac ⌘+Shift+B
  2. Перетащи на неё эту кнопку:
    Лот → калькулятор
  3. Открой лот на Copart и нажми закладку — калькулятор откроется в новой вкладке заполненным, вместе с фотографиями.

Скрипт выполняется внутри страницы Copart, поэтому данные отдаются без помех: для их защиты это обычный клик обычного посетителя. Сама по себе эта страница до Copart достучаться не может — он режет любые запросы со стороны. Считается всё в твоём браузере, никуда ничего не уходит.

Локальный сервер — по желанию, для расчёта не нужен не запущен

Добавляет две вещи: складывает фото и данные лотов на диск (lots/<номер>/) и сам подтягивает курс НБУ. Ссылку тогда можно вставлять прямо в поле Лот вверху, без закладки.

Windows — один раз

git clone https://github.com/artemovdp/car-customs
cd car-customs
start.bat

Дальше запуск — двойной клик по start.bat. Первый раз он сам поставит зависимости, около 150 МБ.

macOS и Linux

git clone https://github.com/artemovdp/car-customs
cd car-customs
pip install -r requirements.txt
python -m playwright install chromium
python serve.py

Потом открой http://localhost:8731 — это та же страница, но с загрузкой лотов и курсом. Исходники: github.com/artemovdp/car-customs

Что входит в таможенную стоимость: цена лота + сборы аукциона + фрахт до границы Украины. Комиссия посредника, ремонт, сертификация и регистрация — не входят.

Акциз = базовая ставка × объём в литрах × коэффициент возраста (максимум 15). Бензин €50 до 3.0 л и €100 свыше; дизель €75 до 3.5 л и €150 свыше; электро €1 за кВт·ч; PHEV фиксированные €100. От цены авто акциз не зависит.

Пенсионный сбор платится при первой регистрации, не таможне. Пороги — 165 и 290 прожиточных минимумов; ставка на каждый сценарий считается отдельно, перескок через порог виден в строке.

Сборы аукциона в авторежиме — грубая оценка, реальные зависят от типа членства Copart. Оценка, не оферта.

Лот

Откроется окно Chromium на несколько секунд — Copart пускает только настоящий браузер. Фото скачаются в lots/<номер>/.

Заполнять автоматически ставить ничего не нужно
  1. Покажи панель закладок, если скрыта — Ctrl+Shift+B на Mac ⌘+Shift+B
  2. Перетащи на неё эту кнопку:
    Лот → калькулятор
  3. Открой лот на Copart и нажми закладку — калькулятор откроется в новой вкладке заполненным, вместе с фотографиями.

Скрипт выполняется внутри страницы Copart, поэтому данные отдаются без помех: для их защиты это обычный клик обычного посетителя — ни окон, ни проверок «вы человек?». Сама по себе эта страница до Copart достучаться не может, он режет любые запросы со стороны. Считается всё в твоём браузере, никуда ничего не уходит.

Локальный сервер — не нужен, если пользуешься закладкой не запущен

Нужен ровно для двух вещей: складывать фото и данные лотов на диск (lots/<номер>/) и подтягивать курс НБУ автоматически. На расчёт не влияет.

Учти цену. С сервером ссылку вставляют в поле Лот вверху, и тогда он сам идёт на Copart — на 10–20 секунд открывается окно Chromium, и время от времени Copart просит пройти проверку «вы человек?». У закладки этого нет: она работает в уже открытой тобой вкладке. Если проверки раздражают — оставайся на закладке.

Windows — поставить один раз

git clone https://github.com/artemovdp/car-customs
cd car-customs
start.bat

Запускать после каждой перезагрузки

Сервер живёт до выключения компьютера — сам он не поднимается. Двойной клик по start.bat, или командой:

cd car-customs
python serve.py

macOS и Linux

git clone https://github.com/artemovdp/car-customs
cd car-customs
pip install -r requirements.txt
python -m playwright install chromium
python serve.py

Потом открой http://localhost:8731 — это та же страница, но с загрузкой лотов и курсом. Индикатор справа от заголовка показывает, поднят сервер или нет. Исходники: github.com/artemovdp/car-customs

Смета ремонта

Загрузи лот — и Claude посмотрит снимки: сработали ли подушки, что реально помято, видно ли силовую. Уточняет смету точнее, чем коды повреждений из карточки.

Итого по смете—

Позиции включаются по полям повреждений из карточки лота. Сними галочку с того, что не пострадало, и поправь цены под своего поставщика. Стапель, верхнюю панель и радар оставляй включёнными, пока не увидел машину живьём: по фото Copart силовую часть не видно. Подушки карточка не показывает вообще — ставь галочку сам, если на фото видно, что они сработали.

Что входит в таможенную стоимость: цена лота + сборы аукциона + фрахт до границы Украины. Комиссия посредника, ремонт, сертификация и регистрация — не входят.

Акциз = базовая ставка × объём в литрах × коэффициент возраста (максимум 15). Бензин €50 до 3.0 л и €100 свыше; дизель €75 до 3.5 л и €150 свыше; электро €1 за кВт·ч; PHEV фиксированные €100. От цены авто акциз не зависит.

Пенсионный сбор платится при первой регистрации, не таможне. Пороги — 165 и 290 прожиточных минимумов; ставка на каждый сценарий считается отдельно, перескок через порог виден в строке.

Сборы аукциона в авторежиме — грубая оценка, реальные зависят от типа членства Copart. Оценка, не оферта.

# Расчёт пригона авто из США (Copart / IAAI) в Украину

## Инструменты в этой папке

| | |
|---|---|
| `lot.py` | `python lot.py "<ссылка>"` — забирает данные лота и все фото в `lots/<номер>/` |
| `analyze.py` | `python analyze.py <лот>` — разбор фотографий через Claude Code |
| `market.py` | `python market.py bmw x3` — цены AUTO.RIA; `--recompute` пересчитывает без сети |
| `journal.py` | `python journal.py report` — прогнозы против фактов |
| `share.py` | `python share.py` — публичная ссылка через туннель Cloudflare |
| `serve.py` | `python serve.py` → `http://localhost:8731` — калькулятор с загрузкой лота по ссылке и курсом НБУ |
| `index.html` | сама страница: три сценария ставки, пороги, обратный расчёт |
| `start.bat` | запуск в один клик |

Уже скачанный лот открывается без браузера: `localhost:8731/?lot=<номер>` —
данные и разбор поднимаются с диска.

**Второй запущенный `serve.py` молча проигрывает порт первому**, и страница
продолжает отдаваться старым кодом. Если правки «не применились» — проверить
`server.log` и убить лишние процессы.

**Доступ по ключу.** Их два: `.access-key` открывает всё, `.guest-key` — всё
кроме журнала сделок. Наружу `share.py` раздаёт гостевой. Отдаются только
`index.html`, `market.json`, `bookmarklet.js` и `lots/` — заметки, лог и
исходники наружу не идут. Свой браузер получает ключ автоматически: `serve.py`
сам открывает страницу со ссылкой при старте.

**Проверено про туннели** (не тратить время заново):

- Cloudflare quick tunnel у этого провайдера **не работает**: DNS резолвится,
  TCP до `api.trycloudflare.com` не проходит — домен режут.
- `serveo` работает, нужен только `ssh` из Windows. Показывает гостю страницу
  предупреждения и **срезает на ней query-строку** — отсюда поле для ключа на
  странице отказа. Слишком частые перезапуски ловят «too many tunnel starts».
- `pinggy` через пайп молчит: баннер со ссылкой требует настоящего терминала.
- Пробрасывать надо на `127.0.0.1`, а не `localhost`: на Windows он резолвится
  сначала в `::1`, сервер слушает IPv4, и туннель отдаёт 502.

Курс НБУ можно взять программно — API `bank.gov.ua` с машины пользователя
отвечает нормально (через WebFetch — 403, не пытаться).

## Роль

Считаю полную стоимость пригона авто из США в Украину и даю честный вердикт по
максимальной ставке. Пользователь (Вадим) кидает ссылку на лот Copart/IAAI или
данные лота — я изучаю информацию и фотографии и выдаю полный отчёт.

**Машина берётся СЕБЕ, не на перепродажу.** Отсюда следует:

- Прибыли нет и считать её незачем. Вопрос стоит иначе: **дешевле пригнать или
  купить такую же в Украине**. Потолок ставки — это точка, где пригон
  перестаёт выигрывать у покупки на месте.
- Налога с продажи (5% ПДФО + 5% ВЗ со второй легковой в году, 18% + 5% с
  третьей) **нет** — он появляется только при перепродаже. Не считать.
- На выходе из расходов только постановка на учёт, а она уже в расчёте:
  пенсионный сбор плюс регистрация в строке «сертификация, брокер».
- Сравнивать по умолчанию с объявлениями **«Був в ДТП»**: на руках будет
  восстановленная после удара машина, и честный аналог — такая же. Сравнение с
  целыми возможно, но тогда это сознательная переплата за небитую.
- Скидка от медианы в этом режиме — не уступка покупателю, а **торг в свою
  пользу**, и он скромный: 5%, а не 10–25%.

В калькуляторе это переключатель «Себе / На перепродажу», по умолчанию «Себе».
Режим «на перепродажу» оставлен рабочим на случай, если планы поменяются.

**Главный принцип: не занижать риски и не давать оптимистичный вердикт ради
вежливости. Нужна цифра, выше которой не ставить.**

## Порядок работы по каждому лоту

### Шаг 1. Проверить актуальные данные (ОБЯЗАТЕЛЬНО, каждый раз)

1. **Курс НБУ (USD, EUR)** — через WebSearch: `курс НБУ долар євро <дата>`
   API `bank.gov.ua/NBUStatService/...` отдаёт **403** через WebFetch — не тратить
   на него вызовы, идти сразу в поиск.
2. **Не менялись ли ставки растаможки** — WebSearch:
   `розмитнення авто <год> зміни ставки акциз пенсійний збір прожитковий мінімум`
3. **Пороги пенсионного сбора** — привязаны к прожиточному минимуму, меняются
   с 1 января каждого года. Пересчитать: `165 × ПМ` и `290 × ПМ`.

Если поиск недоступен — прямо сказать об этом и считать по последним известным
значениям, явно указав дату этих значений.

### Шаг 2. Забрать лот

**Основной способ — скрипт в этой папке:**

```
python lot.py "<ссылка>"
```

Кладёт в `lots/<номер>/`: `lot.json` со всеми полями, все фото в HD,
`page.txt`, сырые ответы API. Дальше читаю фото через Read — это быстрее и
качественнее, чем скриншотить галерею в браузере.

Запасные варианты, если скрипт не сработал:

1. **Chrome-автоматизация** — скилл `claude-in-chrome`, открыть лот в браузере
   пользователя. Фото качать не по одному, а через JSON-эндпоинт:
   `https://www.copart.com/public/data/lotdetails/solr/lotImages/<лот>/USA`
   (открыть его через `navigate` + `get_page_text`), потом скачать HD-ссылки
   обычным `Invoke-WebRequest` — CDN `cs.copart.com` бот-защитой не прикрыт.
2. Попросить прислать данные текстом и **фото прикрепить в чат**.

**Что проверено про бот-защиту Copart** (не тратить время заново):

- WebFetch и `Invoke-WebRequest` → Akamai отдаёт код 200 и страницу блокировки
  (`NOINDEX, NOFOLLOW`, ~1 КБ) вместо JSON. Заголовки и User-Agent не помогают.
- Playwright **headless** режется точно так же, cookies не спасают.
- Работает только браузер **с окном**. Поэтому `lot.py` по умолчанию headed.
- CDN с фотографиями (`cs.copart.com`) открыт — качается чем угодно.
- Серверный прокси (Cloudflare Worker и т.п.) **не решает задачу** — упрётся в
  то же самое, с датацентрового IP даже вернее.

### Шаг 3. Собрать данные лота

Минимальный набор:

- **VIN** — критично. Определяет происхождение (пошлина 10% vs 0%) и комплектацию
- Год выпуска, объём двигателя (л), тип топлива: бензин / дизель / гибрид
  (обычный HEV или PHEV — режимы разные)
- Текущая ставка, Buy It Now
- Тип тайтла: Clean / Salvage / Rebuilt / Cert of Destruction
- Primary + Secondary Damage из карточки лота
- Run & Drive / Engine Start Program / Non-Runner
- Пробег + отметка Actual / Not Actual
- Локация (влияет на внутреннюю доставку до порта)
- Все фото, особенно: подкапотное, салон с рулём и торпедо (подушки),
  открытый багажник с поднятым полом, вид снизу/сбоку

## Формула растаможки (Закон Украины №2611-VIII)

**Таможенная стоимость = цена лота + сборы аукциона + фрахт до границы Украины**

В неё **НЕ входят**: комиссия посредника, ремонт, сертификация, регистрация.
Фрахт — **входит**. Это ошибка №1 во всех «народных» расчётах.

### 1. Пошлина

| Происхождение | Ставка |
|---|---|
| США / Япония / Корея / ОАЭ | **10%** |
| ЕС и Великобритания с сертификатом EUR.1 | **0%** |
| Plug-in гибрид (PHEV) | 5% |
| Электромобиль | 0% |

**Происхождение определяется по VIN, а не по стране покупки.**
BMW/Mercedes с VIN на `5` (США) — это авто из США, EUR.1 не будет. Никогда.

### 2. Акциз = базовая ставка × объём двигателя в литрах × коэффициент возраста

| Тип | до порога | свыше |
|---|---|---|
| Бензин | **€50** (до 3000 см³) | **€100** (>3000 см³) |
| Дизель | **€75** (до 3500 см³) | **€150** (>3500 см³) |
| Электро | €1 за 1 кВт·ч ёмкости батареи | — |
| PHEV | фиксированный €100 | — |

**Коэффициент возраста = текущий год − год выпуска**, максимум **15**, минимум 1.

⚠️ **Спорный ±1 год.** Закон говорит «количество полных календарных лет с года,
следующего за годом выпуска». Часть брокеров считает `год − год выпуска`, часть
таможен применяет **+1**. Разница = базовая ставка × литраж (для 2.0 бензин —
лишние **€100**). Считать по базовой формуле, но **всегда выносить эту строку
отдельно как риск**.

Акциз **не зависит от цены авто**. Только объём + возраст.

### 3. НДС = 20% × (таможенная стоимость + пошлина + акциз)

### 4. Пенсионный сбор

Платится **при первой регистрации, не таможне**. Пороги = 165 и 290 прожиточных
минимумов. **Обязательно проверять, не перескакивает ли сумма через порог** —
это самая частая внезапная переплата.

**База — стоимость авто БЕЗ НДС**, то есть таможенная стоимость из декларации
(проверено 14.08.2026). Ни пошлина, ни акциз, ни НДС в неё не входят. Объект
обложения по закону — стоимость, указанная в договоре купли-продажи, ГТД или
акте оценки. Электромобили от сбора освобождены.

## Экологический стандарт — дедлайн 31.12.2026

- Сейчас для б/у легковых достаточно **Евро-2** (де-факто авто от 1996 г.в.).
- **С 01.01.2027 требование поднимается до Евро-6 для всех**, исключение —
  ввезённое до 31.12.2026 включительно.
- При сроке доставки 6–10 недель: всё, что куплено позже **начала ноября 2026**,
  рискует не успеть растаможиться в старом режиме.
- Для авто примерно до 2015 г.в. это может стать блокером. **Флагать при каждом
  расчёте осенью 2026.**
- Если в техпаспорте нет отметки об экоклассе — нужен сертификат соответствия
  в Украине (время + деньги).

## Формат отчёта (что выдавать на выходе)

### 1. Разбор повреждений по фото

- Что видно, что под вопросом
- **Задета ли силовая структура кузова** — лонжероны, моторный щит, пол багажника,
  стойки, пороги
- Сработали ли подушки безопасности (и сколько)
- Оценка ремонта в Украине: **диапазон, худший и лучший случай**

**Если по фото не видно лонжеронов, пола багажника или моторного щита — сказать
это прямо**, а не гадать в оптимистичную сторону.

### 2. Таблица расходов в ТРЁХ сценариях ставки

Низкая / средняя / высокая. Раскладка по каждой строке. **Налоги в евро и
долларах.** Отдельной строкой — риск +1 года по акцизу.

### 3. Вердикт

- Сколько стоит **купить такую же в Украине** — реалистично, по объявлениям
  «Був в ДТП» нужного года и шильдика, а не «хотелки» с OLX
- **Максимальная ставка, выше которой пригон проигрывает покупке на месте** —
  конкретное число

### 4. Записать прогноз в журнал

По каждому посчитанному лоту — кнопка «Записать в журнал» или
`journal.py`. Потом, когда торги пройдут:

```
python journal.py auction <лот> --sold <сумма>
```

Это единственный способ узнать, попадают ли потолки в рынок. Записывать стоит
и лоты, которые не покупали.

## Что ещё не сделано (обсуждено, приоритеты по убыванию)

1. **Разбор фото в один прогон** — результат плавает между запусками. Union по
   `damaged`, пересечение по `intact`, спорное помечать. Стало важнее с тех
   пор, как `intact` снимает галочки: теперь ошибка разбора занижает смету.
2. **Лоты нельзя сравнить между собой** — журнал показывает историю, но сводной
   таблицы «эти пять на выбор» нет.
3. **Вердикт — одно число.** Чувствительность к ремонту ±30% и цене ±10% не
   показана.

Закрыто и переспрашивать не надо:

- **Налог с перепродажи** — не применяется, машина берётся себе.
- **Стоимость денег во времени** (4–6 месяцев заморозки) — решено не считать.

## Обязательные предупреждения

### Риск переоценки таможней

Таможня может **не принять цену аукциона** и начислить по своей справочной базе.
Для битых авто нужен пакет документов:

- инвойс аукциона
- отчёт о повреждениях (Condition Report)
- фото
- часто — акт оценки от сертифицированного оценщика

Это не «может быть» — это стандартная практика по битым лотам. Всегда включать
в расчёт как отдельный риск-сценарий: посчитать, что будет, если таможня
начислит по справочной стоимости целого аналога.

### Чего не делать

- Не занижать риски
- Не забывать: ремонт и комиссия посредника в таможенную базу **НЕ входят**,
  а фрахт — **входит**
- Не давать оптимистичный вердикт ради вежливости
- Не путать «сработала одна подушка» с «конструктив цел» — это разные вещи
- Не считать акциз от цены авто — он только от объёма и возраста

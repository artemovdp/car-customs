# Калькулятор растаможки: США → Украина

Считает полную стоимость пригона авто с Copart в Украину по Закону №2611-VIII.
Тянет данные лота и фото прямо с Copart, курс — с НБУ, и показывает три
сценария ставки рядом.

## Зачем локально, а не на хостинге

Copart закрыт бот-защитой Akamai. Обычный HTTP-запрос получает код 200 и
страницу блокировки вместо данных — неважно, с какими заголовками и с какого
IP. Проходит только настоящий браузер с окном: headless-режим Akamai тоже
режет. Поэтому загрузка лота работает лишь там, где можно поднять Chromium —
на твоём компьютере.

Страницу можно открыть и без сервера — тогда останется ручной калькулятор:
поля заполняешь сам, считает всё то же самое.

## Запуск

Двойной клик по `start.bat`. Первый раз он поставит зависимости (~150 МБ,
Chromium), дальше стартует за секунду и откроет `http://localhost:8731`.

Вручную:

```
python -m pip install playwright requests
python -m playwright install chromium
python serve.py
```

## Как пользоваться

1. Вставь ссылку на лот Copart → **Загрузить**. На 10–20 секунд откроется окно
   Chromium — так и должно быть.
2. Страница подставит год, объём, топливо и три сценария ставки от оценочной
   розницы; фото лягут в `lots/<номер>/`.
3. Поправь фрахт, ремонт и цену продажи под себя — таблица пересчитается.
4. Смотри строку **Максимальная ставка** — выше неё сделка теряет смысл.

Если Copart попросит проверку, скрипт скажет об этом. Пройди её в открывшемся
окне: cookies осядут в `.browser-profile/`, дальше пойдёт молча.

## Что считается

```
Таможенная стоимость = ставка + сборы аукциона + фрахт до границы
```

Комиссия посредника, ремонт, сертификация и регистрация в базу **не входят**.
Фрахт — **входит**, и каждый его доллар тянет ещё ~32 цента налогов.

| Платёж | Ставка |
|---|---|
| Пошлина | 10% (США, Япония, Корея, ОАЭ) · 0% (ЕС/UK с EUR.1) · 5% (PHEV) |
| Акциз | базовая ставка × объём в литрах × возраст (макс. 15) |
| НДС | 20% от (ТС + пошлина + акциз) |
| Пенсионный сбор | 3 / 4 / 5% — пороги 165 и 290 прожиточных минимумов |

Базовые ставки акциза: бензин €50 до 3.0 л и €100 свыше; дизель €75 до 3.5 л
и €150 свыше; электро €1 за кВт·ч; PHEV фиксированные €100. **От цены авто
акциз не зависит** — только объём и возраст.

## Чего он не делает

- **Не смотрит фотографии.** Задет ли лонжерон, сработали ли подушки, сколько
  будет стоить ремонт — это оценка человека или модели, не JavaScript.
- **Не знает реальных сборов Copart.** Авторежим — грубая оценка от ставки,
  реальные зависят от типа членства. Перепроверяй по своему аккаунту.
- **Не гарантирует, что таможня примет инвойс.** На битые авто нужен пакет:
  инвойс, Condition Report, фото, часто акт оценки. Блок «Риск переоценки»
  показывает, во что обойдётся отказ.
